Privacy policy

Effective date: 11 October 2026

This policy describes how BYOKit handles Google user data when an app uses BYOKit's Google sign-in. It covers the sign-in used by the @byokit/connect and @byokit/accounts packages.

What Google data is accessed, and why

BYOKit asks Google only for the permissions the app needs. BYOKit itself reads none of this data; the app on the person's own device uses it on the person's behalf. The possible permissions are:

PermissionWhat it lets the app do
Sign-in
openid, email, profile		 Read the signed-in Google account's basic profile and email address, so the app can show which account is connected.
Google Cloud
cloud-platform, userinfo.email, userinfo.profile		 Run Google Code Assist (Gemini) against the person's own Google account, using the plan they already have.
Gmail (read-only)
gmail.readonly		 Read the person's Gmail messages so the app can show, search or summarise them.
Google Drive
drive.file		 Access only the files the person opens with the app or that the app creates — never the rest of their Drive.
Google Calendar
calendar.events		 Read and add the person's calendar events on their behalf.

An app requests only the permissions it needs for the feature the person is using. Which of the above appear depends on the app.

Where the data and tokens go

The app stores the Google access and refresh tokens on the person's own device or computer, in the app's own local store. Tokens are never sent to BYOKit, because BYOKit operates no servers of its own. Network requests go directly from the person's device to Google's own endpoints (for example accounts.google.com and oauth2.googleapis.com).

BYOKit does not receive, collect, see or hold the person's Google tokens, Google data or Google account. There is no BYOKit account, no BYOKit backend and no BYOKit analytics.

Google API Limited Use disclosure

BYOKit's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

No selling or sharing

BYOKit does not sell Google user data, and does not share it with third parties. It does not use Google user data for advertising, and does not use it to train or improve generalised AI or machine-learning models.

How to revoke access

The person can remove the app's access to their Google account at any time from Google's account permissions page: myaccount.google.com/permissions. Signing out inside the app also deletes the locally stored token from the device.
