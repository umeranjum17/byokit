# OpenClaw extended-stable engine and native Workshop

The built public `@byokit/openclaw` entry boots the exact extended-stable engine, lists and reads complete native Workshop instructions from one agent's persistent collection, refuses another agent's read and a third-party provider install, then makes one fresh MiniMax M3.1 Flash chat turn.

## Drive

Explicit live-route authorization and a sanctioned key file path are prerequisites. Never discover keys in installed apps, read keys from environment, print/copy the key, or retry the model turn. API-key billing remains billed per use; trial credit is not proof of zero charge. Native `addKey` setup may make its own verification request in addition to the one chat turn.

From a clean committed tree after build/doctor, open a unique done-done run and invoke:

```sh
node .agents/skills/done-done-verify-byokit/capture/openclaw-stable-engine.mjs <run-evidence-directory> <task-owned-disk-engine-directory> <sanctioned-key-file>
```

Run under a throwaway HOME/XDG, with supported Node/npm on PATH, through the host's memory gate and heavy-job lock. Engine installs live on disk, never tmpfs; the short temporary app home is deleted in `finally`. The recipe uses only public built package entries, records the actual engine version, native catalog id, typed unavailable outcome, activation result, unique reply and run id, and scans its log/JSON captures for the exact key before returning. No screenshots are needed for this SDK-only change.

Seal the run only after all validation and the single real turn finish. Judge `stable-engine.log` and `steps.json` and receipt the exact clean HEAD; do not reuse a prior run's media/logs. Failure or unavailable judge remains unproven.
