- Let native runtime hosts reference an explicit app-owned Claude folder with `cliAccounts.managedFolders`, without deleting those folders on cancelled or failed sign-in. Remote CLI starts support cancellation during URL parsing and an orderly `close()`; cancellation wins over a late successful native status readback. A signing row left by a crashed login no longer blocks a phone sign-in as busy once its sign-in lock holder is gone; a remote spawn holds the same `.byokit-signin-lock` as the shell command. Both paths record the native child's PID and retain the lock until that child exits, so a crashed wrapper cannot hide a live login. Long phone waits share one child-exit observer; a failed PID-record write stops and reaps the native child before unlocking and reporting failure.
