- Each managed OpenCode account now keeps its own sign-in store, database, state and cache: `launch`, `launchEnv` and the sign-in env set `XDG_DATA_HOME`, `XDG_STATE_HOME` and `XDG_CACHE_HOME` under the account folder (and unset `OPENCODE_DB`), so an account never reads or writes the person's own `~/.local/share/opencode`; `remove` deletes them. `launch` results carry `args`, the flags the start needs: `['--standalone']` on OpenCode 2.x, so two accounts run at once instead of the second failing on 2.x's shared server port.
