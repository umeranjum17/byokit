- FIX: file VAD (`settings.vad.enabled`) no longer makes a long take slower than leaving it off. Each speech range used to be its own decode, and every decode pays a full Whisper encode, so a take full of short pauses took about twice as long. A long take now reads exactly the ungated windows and skips the silent ones, so its text matches the ungated text. A take within one window is one read from first speech to last. A long take now returns one range-level segment instead of one per speech range.
