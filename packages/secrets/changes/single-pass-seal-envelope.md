- FIX: `encrypt()` no longer builds a second full-size copy of the payload: the authenticated `{ service, text }` envelope is emitted through bounded chunk-wise JSON escaping (byte-identical to the previous whole-string stringify, including surrogate pairs kept in one chunk), so sealing a large string allocates one snapshot-sized string instead of two and cannot hit the runtime string limit on the envelope. Envelope bytes, headers and decrypt compatibility are unchanged.
