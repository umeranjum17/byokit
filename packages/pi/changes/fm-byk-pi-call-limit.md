- `maxToolCalls` on `createPiKit` (default 30) bounds the tool calls of one turn, so a model repeating a tool call cannot spend without bound. At the cap the bot emits `{ type: 'limit', toolCalls, limit }` and the run ends once as `{ ok: false, message }` naming the limit; the process stays up and the next prompt counts from zero. Zero, negative and fractional values are refused with the new `bad-limit` error.
