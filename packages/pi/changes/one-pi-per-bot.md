- FEATURE: `@byokit/pi`, one Pi process per bot. `createPiKit({ stateDir, idleMs? }).bot({ id, folder, session, extensions?, env? })` returns a bot with `prompt`, `steer`, `followUp`, `abort`, `stop` and `on`: Pi starts when there is work, stops after `idleMs`, and the next message picks the same session back up, after a crash too. Each bot has its own Pi home, session folder and extension list and only its own `AGENTS.md` (Pi's walk up parent folders is off), with an environment built from nothing but `PATH`; the person's own `~/.pi` is never used and is refused as a state folder. Pi is an exact peer (1.5.0), any other version is refused, and only `src/transport.ts` knows Pi, so no Pi type or record reaches the app. No sign-in or provider yet.
