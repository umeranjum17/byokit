- FEATURE: `setup()` gives the cloud computer its secure address as its own step. With `address: { hostname, port, onStep? }` it emits `securing` (`setup.securing` words) after `installing`: the kit confirms the person's tailnet name, or joins it (`onStep` carries the sign-in link), then privately serves the app's loopback `port` on it (`tailscale serve --tcp`, read back before the step), so a recipe used this way no longer serves its own port.
- FEATURE: `pairEnrol` now ends with a receipt the phone can pair with. After `bindPhoneKey`, the host writes `phoneReceipt(host, key)` to `<workDir>/.byokit/outbox/receipt.json`; `pairEnrol` reads it back as the run user, checks it is for the delivered phone key, and the `pairing` step carries `receipt: { host, device, urls }` (the host's public key, the phone's device on it, and `ws://<tailnet name>:<port>`). The phone opens a real `@byokit/pair` `DeviceLink` with that receipt and its own secret key alone. Breaking for hosts that enrol through `pairEnrol`: they must write the receipt, or the gate fails `timeout` after a minute; a receipt for another phone fails `owner-enrolled`.
