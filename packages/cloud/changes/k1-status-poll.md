- FEATURE: `status(m, { app, label })` is the one read a phone polls through create, install, stop, start and delete: it resolves `{ machine, host, words }`, asks the host only while the machine is on (so no command reaches a machine that is still being set up or is asleep), and gives the one plain sentence to show. The fakes now model the real provider more closely: `fakeProvider({ createReads })` and the loopback Boat server's `slowCreateReads` keep a new machine `creating` for a few reads, as Boat's create resolves before the machine is on; both restart enabled units on every wake (a wake is a cold boot); a command sent to a fake machine that is not on fails `unreachable`; and a removed fake machine reads `gone` instead of `on`.
