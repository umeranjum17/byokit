- FEAT: `@byokit/outbox` — a durable outbound message queue in one fsynced JSON store. Every mutation is revision-checked (stale revisions reject), a cancel accepted while a message is still queued always wins (`flush` never invokes the sender for it), the `queued` → `sending` claim is durable before the sender is invoked, and a cancel that loses that race returns `too-late` instead of a false success. Interrupted sends stay `sending` with an unknown outcome: the kit never redispatches them, never claims delivery, and never invents exactly-once transport guarantees; `resolve` records what the app learned from the transport. No sender, transport, credentials or network are bundled: the app passes the sender and every test uses fakes.
